# Assembly image manifest

Captions describe visible actions; words and check/cross marks belong in the HTML.

Only the processor heatsink is installed in these pictures. Breadboard row 1 is nearest the Pi; holes a–e face the header/FINGER wall, and f–j face the USB-C wall.

Printed shapes come from the final screw-free CAD. Reference components and flexible cable routes are simplified. The wrong J-clip view illustrates elastic deflection; it is not a strain simulation.

The parts sheet shows A, B, C, D, F, G, two J clips, T1, T2 and T3. Label anchors are in [parts_printed.json](parts_printed.json). Re-render AST images from hardware/ with `manual/src/render_all.sh`.
